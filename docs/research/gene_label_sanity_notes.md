# 基因标签检查 · Gene-label sanity checks

[中文](#中文) · [English](#english)

## 中文

检查完整集合与主子集的标签分布。在划分与基线训练前检查管家基因锚点。使用 `S_defined_main` 区分有定义与缺失的稳定性标签。

---

## English

Inspect label distributions in both the complete set and the main subset. Check housekeeping-gene anchors before training. Use `S_defined_main` to identify rows with defined tissue-stability labels.
