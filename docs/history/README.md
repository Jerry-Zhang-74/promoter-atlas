# 历史研究档案 · Research history

## 中文

历史材料按模型版本与实验批次归档。可从以下入口查找：

- [模型版本](../../models/README.md)：权重、模型卡、评估、日志和训练源码。
- [实验批次](../../experiments/README.md)：每批代码、数据、结果和运行记录。
- [版本沿革](../VERSION_HISTORY.md)：实际版号、原始名称和文件时间。
- [研究笔记](../research/)：各阶段的方法与决策。
- [目录规范](../PROJECT_STRUCTURE.md)：分类规则及历史脚本运行入口。

旧索引分别保存在 [model-index.md](model-index.md) 和 [model-archive-notes.md](model-archive-notes.md)。其中的路径对应原始记录；当前位置可在 [路径对照表](../../artifacts/manifests/PATH_MAP.json) 查询。

## English

Historical material is organized by model version and experiment batch:

- [Model versions](../../models/README.md): weights, cards, evaluations, logs and training source.
- [Experiment batches](../../experiments/README.md): code, inputs, results and runtime records for each batch.
- [Version history](../VERSION_HISTORY.md): release identifiers, original names and file timestamps.
- [Research notes](../research/): methods and decisions from each stage.
- [Directory conventions](../PROJECT_STRUCTURE.md): filing rules and the historical-script entry point.

Earlier indexes are retained in [model-index.md](model-index.md) and [model-archive-notes.md](model-archive-notes.md). Their original paths resolve through the [path map](../../artifacts/manifests/PATH_MAP.json).
