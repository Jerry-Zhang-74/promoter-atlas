## 中文

汇总当时已有模型指标，为阶段比较图提供固定输入。`source_metrics.json` 保存指标快照，`figure_manifest.json` 将图表与来源记录关联。

阅读这些数字时沿用各来源的任务、标签单位和划分；后续反向互补检索审计及修订快照见 batch15。

- [指标来源](reports/source_metrics.json)
- [图表清单](reports/figure_manifest.json)
- [后续划分审计](../batch15/README.md)

## English

Collect existing model metrics into fixed inputs for the stage comparison figures. `source_metrics.json` stores the snapshot and `figure_manifest.json` connects figures to their source records.

Interpret each metric with its original task, label units, and split. The subsequent reverse-complement retrieval audit and revised snapshot are in batch15.

- [Metric sources](reports/source_metrics.json)
- [Figure manifest](reports/figure_manifest.json)
