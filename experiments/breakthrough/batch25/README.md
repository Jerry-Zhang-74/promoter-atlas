# batch25 · 启动子结构与短串联重复数据检索 / Promoter architecture and short-tandem-repeat data retrieval

[中文](#中文) · [English](#english)

## 中文

调查新的启动子实测来源，包括 GSE245191 的启动子结构/位置实验和 GSE306816 的近端短串联重复实验。记录论文元数据、下载尝试、文件大小与哈希，并核对来源是否已进入此前开发过程。

`source_manifest.json` 是已取得材料的索引；`source_attempts_summary.json` 逐次记录成功、部分完成和失败的下载，便于按原来源续接。该批输出服务于后续 STR 变体实验的数据准备。

## English

Investigate additional measured promoter sources, including promoter architecture/position experiments in GSE245191 and proximal short-tandem-repeat experiments in GSE306816. Record publication metadata, retrieval attempts, sizes, hashes, and prior source exposure.

`source_manifest.json` indexes acquired materials; `source_attempts_summary.json` records successful, partial, and failed retrievals for continuation from the original sources. These outputs support subsequent STR-variant data preparation.
