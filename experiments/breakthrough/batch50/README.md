## 中文

汇总本地 293FT 适用性、公开同测定迁移表现以及候选选择结果，形成阶段路线说明。每个展示数字映射到来源文件、JSON 字段或表格行、单位、样本范围和 SHA。

`source_evidence_map.json` 给出图表到来源的映射，并指向 batch49 的可运行入口。`correction_01` 保留一次追加修订及其来源校验，阅读阶段图表时可沿索引返回原始指标。

- [图表证据映射](reports/source_evidence_map.json)
- [追加修订来源](reports/correction_01/correction_source_sha.json)

`source_evidence_map.json` maps figures to evidence and points to the runnable batch49 entry point. `correction_01` retains an additive correction and source checksums, allowing each displayed metric to be traced to its record.
