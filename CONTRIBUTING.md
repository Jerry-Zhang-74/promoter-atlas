# Contributing

Open an issue with a reproducible example before proposing a substantial change.
Include the release version, operating system and Python/PyTorch versions. Keep
credentials, private samples and large raw data out of issues and commits.

Run `python verify_release.py` for inference changes. Preserve separate E/S/B
endpoints, data provenance and evaluation limits; do not report demo checks as
scientific validation. Contributions are made under this repository's MIT license.
